# File inventory

- `src/analyze_case30_buses.py`: detailed exploratory analysis of the IEEE-30 predictions. This is the latest uploaded version supplied for organization.
- `src/compare_case14_case30.py`: comparison of active-power prediction errors between IEEE-14 and IEEE-30.
- `src/analyze_active_power_compensation.py`: scenario-level error-compensation analysis for buses 0 and 1 and across buses.
- `outputs/`: local input parquet files and generated intermediate outputs. Not committed to Git by default.
- `figures/`: reserved for the small set of final, reviewed figures intended for the challenge submission.
